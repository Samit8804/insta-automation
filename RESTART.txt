InstaFlow - Restart Steps (after laptop shutdown)
=================================================

1. Open terminal in E:\automation

2. Start automation service:
   cd automation
   python server.py

3. Wait 8 seconds, then expose it via Tailscale Funnel:
   tailscale funnel --bg 8000

4. Start backend:
   cd ..\backend
   node src\index.js

5. Start frontend (optional - Vercel handles this):
   cd ..\frontend
   npm run dev

6. Verify everything:
   - Automation: http://localhost:8000/status
   - Backend:    http://localhost:5000/api/auth/login
   - Frontend:   https://insta-automation.vercel.app

That's it. The Render backend will find your automation
automatically via the Tailscale Funnel URL.
