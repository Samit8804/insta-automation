InstaFlow - Restart Steps (after laptop shutdown)
=================================================

1. Open terminal and switch to E drive:
   E:
   cd E:\automation\automation

2. Start automation service:
   python server.py

3. Wait 10 seconds, then log into Instagram in the Chrome window.
   Once logged in, save session:
   curl http://localhost:8000/savesession -X POST

4. Expose via Tailscale Funnel:
   tailscale funnel --bg 8000

5. Start backend:
   cd E:\automation\backend
   node src\index.js

6. Verify:
   - Automation: http://localhost:8000/status
   - Frontend:   https://insta-automation-sable.vercel.app
